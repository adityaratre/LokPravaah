LokPravaah Cloudflare UPI Worker — Patch Instructions

1. Back up your existing local LokPravaah GitHub Desktop clone.
2. Extract this ZIP into the repository ROOT, allowing overwrite of included files. Do NOT replace/delete the hidden .git folder.
3. Before pushing, create GitHub Actions repository secrets CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID (see CLOUDFLARE_UPI_SETUP.md). The included action tests and deploys the Worker when Worker files change.
4. Commit and push to main using GitHub Desktop.
5. Follow CLOUDFLARE_UPI_SETUP.md in order: Supabase SQL, Worker environment/secrets, Supabase webhook, Cloudflare Pages build variables, Android pairing, and end-to-end tests.
6. Do not enable public real donations until a genuine receiving VPA is configured and a signed receiving-bank notification is verified.

This is a donation-focused Worker replacement, not a full port of all legacy YouPI PG services. The package does not contain your private secrets, local databases, or live account settings.
